The "scripting" permission is required to register the content script in the MAIN world via chrome.scripting.registerContentScripts().

The content script must run in the MAIN world, not the default isolated world, because it wraps the page's global `__d` function before Gizmo's Metro runtime assigns it. `__d` is Metro's module registrar and lives on the page's `globalThis`. An isolated-world script cannot see or wrap it. The wrapper does not fetch or execute remote code. After each of Gizmo's own module factories returns, it changes three in-memory reads: subscription status reports "subscribed", `isSubscribedStore.get()` returns true, and the import-cooldown env flag is the string "true".

The extension framework (Plasmo) registers MAIN-world scripts from the background service worker using chrome.scripting.registerContentScripts(), which requires the "scripting" permission. No other scripting API is called. The registered file is packaged inside the extension.
